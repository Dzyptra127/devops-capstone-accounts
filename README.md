# Layanan Mikro Akun Pelanggan

Proyek Capstone DevOps — membangun layanan mikro untuk pengelolaan data akun pelanggan,
mencakup pengembangan RESTful API, integrasi berkelanjutan (CI), penerapan keamanan,
kontainerisasi dengan Docker, dan penyebaran ke Kubernetes.
