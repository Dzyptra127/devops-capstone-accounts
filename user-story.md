# Templat Cerita Pengguna

## Format
Sebagai [peran pengguna], saya ingin [tindakan/fitur], agar [manfaat/tujuan].

## Kriteria Penerimaan
- [ ] Syarat keberhasilan pertama
- [ ] Syarat keberhasilan kedua
- [ ] Semua pengujian otomatis berhasil

## Contoh Cerita Pengguna
Sebagai pengguna sistem, saya ingin melihat daftar semua akun, agar saya dapat meninjau data pelanggan dengan mudah.

- Daftar menampilkan semua akun yang terdaftar
- Data ditampilkan dengan format yang jelas dan mudah dibaca
- Respons selesai dalam waktu kurang dari 2 detik
